# roadmaps

Agentically generated interactive learning roadmaps in the style of [roadmap.sh](https://roadmap.sh) — structured, visual developer learning paths with progress tracking, curated resources, and prerequisite-based topic ordering.

Each roadmap is a self-contained HTML file generated from a structured JSON data source. No build tools or servers required — just open in a browser.

## How It Works

Roadmaps are generated by a multi-agent pipeline built on [antfarm](https://github.com/funsaized/mr-krabs) — a workflow orchestration framework for autonomous AI agents. The pipeline coordinates 7 specialized Claude agents across 7 steps:

```
 ┌─────────┐    ┌────────────┐    ┌──────────┐    ┌─────────────┐
 │ Planner  │───▶│ Researcher │───▶│ Verifier │───▶│ Synthesizer │
 └─────────┘    └────────────┘    └──────────┘    └─────────────┘
                  (per domain)     (per domain)           │
                                                          ▼
                ┌─────────┐    ┌──────────┐    ┌───────────┐
                │ Builder │◀───│ Reviewer │◀───│ Architect │
                └─────────┘    └──────────┘    └───────────┘
```

1. **Plan** — The **Planner** decomposes a topic into learning domains (max 15), maps prerequisite dependencies, assigns difficulty levels, and produces a structured research plan
2. **Research** — The **Researcher** conducts deep web research on each domain in parallel, finding authoritative resources (courses, videos, books, exercises, docs) with verified URLs
3. **Verify** — The **Verifier** quality-checks each research output for depth, source quality, resource variety, and actionability. Failed domains are sent back to research
4. **Synthesize** — The **Synthesizer** combines all verified research into a unified knowledge map — deduplicates concepts, builds the dependency graph, ranks resources, and produces `roadmap-data.json`
5. **Architect** — The **Architect** designs the visual roadmap structure: sections, node hierarchy, prerequisite edges, color coding, layout coordinates, and checkpoint nodes. Outputs `roadmap-final.json`
6. **Review** — The **Reviewer** validates the roadmap for JSON integrity, referential correctness, graph acyclicity, resource coverage (2+ per node), domain completeness, and logical ordering. Fixes critical issues directly
7. **Build** — The **Builder** generates the final interactive HTML roadmap as a single self-contained file with embedded CSS/JS, progress tracking, and the full roadmap data

The pipeline is defined in [`topic-mastery-roadmap/workflow.yml`](https://github.com/funsaized/mr-krabs/tree/main/workflows/topic-mastery-roadmap) and takes a task file describing the topic scope, target audience, AI taxonomy, and success criteria. A new roadmap is generated by adding a task file and running the workflow.

## Features

- **Progress tracking** — Check off topics as you learn. Progress persists in localStorage.
- **Detail panel** — Click any topic to see descriptions, key concepts, sub-topics, prerequisites, and curated resources
- **Search and filter** — Find topics by name or concept. Filter by difficulty level.
- **Prerequisite locking** — Topics with unfinished prerequisites are locked until you complete them
- **Section collapse** — Expand/collapse sections to focus on what matters
- **Prerequisite navigation** — Click prerequisite links to jump directly to the referenced topic
- **Fully offline** — Each roadmap is a single HTML file with zero external dependencies (except fonts)

## Repository Structure

```
roadmaps/
├── README.md
└── <roadmap-name>/
    ├── roadmap.html                   # Interactive roadmap (open in browser)
    ├── generate-roadmap.py            # HTML generator from roadmap-final.json
    ├── README.md                      # Roadmap-specific documentation
    ├── review-notes.md                # Automated review results
    ├── architecture/
    │   ├── roadmap-final.json         # Final roadmap data (nodes, edges, resources, layout)
    │   └── layout-spec.md             # Visual layout specification
    ├── research/
    │   ├── learning-plan.md           # Domain decomposition and dependency graph
    │   └── domains/                   # Per-domain deep research documents
    ├── synthesis/
    │   ├── roadmap-data.json          # Synthesized roadmap data (pre-architecture)
    │   ├── knowledge-map.md           # Unified concept inventory
    │   ├── dependency-graph.md        # Topic dependency analysis
    │   ├── cross-references.md        # Inter-domain connections
    │   ├── learning-paths.md          # Recommended learning sequences
    │   └── resource-catalog.md        # Deduplicated, ranked resource index
    └── ...
```

The pipeline source lives in [mr-krabs/workflows/topic-mastery-roadmap](https://github.com/funsaized/mr-krabs/tree/main/workflows/topic-mastery-roadmap) and includes agent definitions, skills, and the workflow YAML.
