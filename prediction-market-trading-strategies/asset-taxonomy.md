# Asset Taxonomy: Prediction Market Trading Strategies

## Asset Types

### articles
News articles, blog posts, press releases, industry coverage.
Metadata: title, author, publication, date, url, relevance_score

### papers
Academic papers, whitepapers, research reports, working papers.
Metadata: title, authors, journal/venue, year, doi, abstract

### documentation
API docs, technical specifications, platform guides, SDK references.
Metadata: title, platform, version, url, last_updated

### code
Repositories, code snippets, libraries, SDKs, trading bot examples.
Metadata: repo_url, language, stars, last_commit, description

### data
Datasets, statistics, market data, historical prices, volume data.
Metadata: source, format, date_range, size, description

### discussion
Forum threads, Reddit posts, HN discussions, Twitter threads.
Metadata: platform, author, date, url, upvotes, reply_count

### reports
Industry reports, analyst briefings, market research, regulatory filings.
Metadata: title, publisher, date, url, type

### media
Videos, podcasts, presentations, infographics, conference talks.
Metadata: title, creator, platform, duration, date, url
